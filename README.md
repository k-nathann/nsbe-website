# Calvin University NSBE Chapter Website

![NSBE](https://img.shields.io/badge/NSBE-Calvin%20University-blue)
![HTML](https://img.shields.io/badge/Built%20with-HTML%2FCSS%2FJS-orange)

The official website for the **Calvin University Chapter of the National Society of Black Engineers (NSBE)**. Built to improve member engagement, centralize chapter resources, and showcase events and opportunities for current and prospective members.

---

## Features

- **Chapter Information** — Learn about Calvin's NSBE chapter, its mission, and leadership team
- **Events** — Stay up to date with upcoming meetings, workshops, and national conventions
- **Resources** — Access member resources, career tools, and chapter documents
- **Responsive Design** — Optimized for both desktop and mobile viewing
- **High Performance** — Achieves 95+ Lighthouse scores across performance, accessibility, and SEO

---

## Getting Started

### Prerequisites

All you need is a modern web browser. No frameworks or package managers required.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd <repo-name>
   ```

3. **Open the site locally**

   Simply open `index.html` in your browser:
   ```bash
   open index.html
   ```
   Or use a local dev server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for a better development experience.

## About NSBE

The National Society of Black Engineers is one of the largest student-managed organizations in the country. Our mission is to increase the number of culturally responsible Black engineers who excel academically, succeed professionally, and positively impact the community.

🔗 [National NSBE Website](https://www.nsbe.org)
